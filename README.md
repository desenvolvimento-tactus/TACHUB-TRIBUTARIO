# TacHub Tributário — instaladores

Este repositório guarda só os instaladores do TacHub Tributário, nas
[Releases](../../releases). O código-fonte fica em um repositório privado.

O programa instalado consulta a release mais recente daqui e se atualiza
sozinho. Cada release traz a linha `SHA256:` do instalador; sem ela, o programa
não instala a atualização.

Para instalar pela primeira vez, baixe o `Instalar_TacHub_Tributario_vX.Y.Z.exe`
da release mais recente e execute.
